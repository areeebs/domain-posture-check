# Security policy

This is an early learning project, not a production scanner. Please do not rely on it as the sole control for protecting a public service.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository if it is enabled. If private reporting is unavailable, contact the maintainer privately before disclosing details publicly. Do not include real target names, private IPs, certificates, or scan reports in a public issue.

## Scope

Security reports about the tool itself are welcome. The tool is designed to make one root HTTPS request to a public hostname supplied by the operator. Do not use it to assess a domain unless you own it or have explicit authorization.
